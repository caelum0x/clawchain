# Incentive Loop Design

Phase 13 Track G incentive framework baseline.

## Core Loops

1. Operator loop:
- provide runtime/node availability -> receive network + service rewards.
2. Builder loop:
- publish useful skills/integrations -> receive usage-driven demand.
3. Trust loop:
- deliver reliably -> improve reputation -> increase task/marketplace opportunity.

## Required Design Inputs

- fee policy and reward distribution assumptions
- staking/deposit policy interactions
- reputation signal weighting for economic outcomes

## Guardrails

- anti-spam/economic policy gates remain mandatory
- incentive changes require governance review and rollout notes
