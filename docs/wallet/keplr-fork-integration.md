# Keplr Fork Integration for ClawChain

This repo now vendors and patches three upstream repos for Claw wallet integration:

- `vendor/keplr-wallet`
- `vendor/keplr-chain-registry`
- `vendor/phishing-block-list`

## What was integrated

### 1. Keplr chain-registry entries

Added Cosmos chain registry files:

- `vendor/keplr-chain-registry/cosmos/clawchain.json`
- `vendor/keplr-chain-registry/cosmos/clawchain-testnet.json`

Added image assets:

- `vendor/keplr-chain-registry/images/clawchain/chain.png`
- `vendor/keplr-chain-registry/images/clawchain/uclaw.png`
- `vendor/keplr-chain-registry/images/clawchain-testnet/chain.png`
- `vendor/keplr-chain-registry/images/clawchain-testnet/uclaw.png`

### 2. Keplr extension native chain embedding

Patched `vendor/keplr-wallet/apps/extension/src/config.ts` to include:

- `clawchain-1` (mainnet)
- `clawchain-testnet-1` (testnet)

with:

- bech32 prefix: `claw`
- denom: `uclaw` / display `CLAW`
- gas price defaults: low `0.01`, average `0.025`, high `0.04`

## Endpoint sources used

- Mainnet endpoints from `docs/external-integrator-validation.md`
- Testnet endpoints from `testnet/public.env.example`

## Quick verification

Run:

```bash
bash scripts/wallet/verify-keplr-fork.sh
```

## Build upstream Keplr extension (from vendor)

```bash
cd vendor/keplr-wallet
yarn install
yarn build
```

Build outputs are generated by upstream under:

- `vendor/keplr-wallet/apps/extension/build/manifest-v3`
- `vendor/keplr-wallet/apps/extension/build/manifest-v2`

## Notes

- Upstream Keplr mobile app source is not included in this repository. This fork work currently targets the extension codebase in `vendor/keplr-wallet`.
- Website wallet custody is intentionally disabled in `web/`; production custody/signing path is extension/mobile.
