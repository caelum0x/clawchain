# Public Status + Incident Communication Workflow

Phase 13 Track F communication policy.

## Channels

- Status page / public endpoint
- Operator channel
- Integrator/partner update channel

## Incident Communication Stages

1. Acknowledge (within 15 minutes for critical incidents)
2. Investigate (post updates at agreed interval)
3. Mitigate (publish action + impact updates)
4. Resolve (publish resolution summary)
5. Postmortem (publish owner-reviewed summary)

## Message Minimums

Each public update includes:

- incident identifier
- current impact scope
- current status
- next update ETA (UTC)
